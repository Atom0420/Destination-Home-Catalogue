# Limits and next work

- Catalogue metadata and public image content are obtained separately; neither collection is bundled here.
- The configured online endpoint, schema and ImageArchive branch are external dependencies. Repository preparation did not perform a fresh sync or check current availability.
- Some items have no public preview. An empty picture does not mean metadata or UUID copying failed.
- Resume is limited to matching-endpoint checkpoints younger than one day. Checkpoints are periodic, so interrupted work may repeat pages.
- No formal release version, automated test project or source license grant was supplied.
- Theme/layout verification includes simulated scaling; actual display-DPI transitions, accessibility and multi-monitor behavior still need separate acceptance.
- Appearance settings need a writable application Data directory. A save failure leaves the visible selection applied but may lose it on restart.

Next work: validate the current service contract, add authored checkpoint/pagination fixtures and repeat data-backed offline UI checks after future interface changes.
