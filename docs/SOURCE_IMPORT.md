# Source checkpoint

The repository preserves the standalone viewer's seven source/project/script files and the October 3 interface checkpoint, including its theme controls, screenshot and offline QA record.

The project is rooted here and builds independently. Its namespace and executable identity are `DestinationHome.Catalogue`; the update script uses that executable and a repository-relative output directory. No runtime behavior was otherwise changed during source separation.

Build intermediates, published binaries, IDE caches, downloaded metadata, image collections, personal paths and local update logs are excluded. No historical commits or release tags have been fabricated.
